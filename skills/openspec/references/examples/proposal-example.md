# 提案：添加深色模式支持

## Why

用户反馈在低光环境下使用应用时，浅色主题造成视觉疲劳。竞品均已支持深色模式，这是现代应用的基础功能。添加深色模式将提升用户体验和产品竞争力。

## What Changes

- 添加全局主题切换机制（浅色/深色/跟随系统）
- 为所有 UI 组件提供深色样式变体
- 将用户主题偏好持久化到 localStorage
- 在设置页面添加主题选择控件

## Impact

- **前端**：所有组件需支持 `data-theme` 属性或 CSS 变量
- **设计系统**：需更新颜色 token 定义
- **文档**：用户指南需更新截图和说明
- **测试**：视觉回归测试需覆盖两种主题

## Scope

### In Scope

- Web 应用的主题切换
- 主题偏好持久化
- 跟随操作系统主题偏好

### Out of Scope

- 移动端原生应用（另起变更）
- 邮件模板主题（保持浅色）
- 第三方嵌入组件（不受控）

## Risks

| 风险 | 可能性 | 影响 | 缓解措施 |
|------|--------|------|----------|
| 组件遗漏导致主题不一致 | 中 | 中 | 建立主题检查清单，视觉回归测试 |
| 第三方库不支持深色模式 | 低 | 高 | 预先评估依赖库，准备替代方案 |
| 用户偏好与系统偏好冲突 | 低 | 低 | 明确优先级：用户手动选择 > 系统偏好 |

## Rollback Plan

- 功能开关：`featureFlags.darkMode`
- 关闭开关后回退到浅色模式，清除用户主题偏好
- 可在 5 分钟内完成回滚
