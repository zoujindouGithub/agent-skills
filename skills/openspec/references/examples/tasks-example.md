- [ ] 所有组件在两种主题下正确渲染
- [ ] 系统偏好变化时实时跟随（当选择"跟随系统"）
- [ ] 通过全部单元测试和视觉回归测试
- [ ] 无障碍对比度符合 WCAG AA 标准
